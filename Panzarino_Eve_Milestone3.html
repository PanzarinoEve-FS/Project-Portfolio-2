Milestone 3 overview

The app is functional end to end: five routed views on a Node/Express backend and a MongoDB database, drawing on five free APIs and two libraries beyond React.

This milestone I finished gathering the transgender surgery data, got the heatmap drawing LGBTQIA+ acceptance by ZIP from review data, built the account and favorites system, and committed every collection into the repo so it runs on a clean clone with one seed command.

Libraries & persistent data

React Leaflet

1st libraryreact-leaflet.js.org

Chosen for the synergies with location data on APIs. Tutorial: youtu.be/AeiWsDYLjvA

A set of map components display information from the APIs and MongoDB.

Recharts

2nd libraryrecharts.github.io

A really cute solution to needing an interactive list of zip codes and the businesses within them with a safety score.

Used in the heatmap ZIP code detail section.

MongoDB

Persistent data

Stores surgeon search data, review data and the CEI scores — I couldn't find an API, so I collected some data myself.

All surgeon data and all review data for the ZIP heatmap search live in MongoDB.

APIs & data sources

GeoJS

APIgeojs.io

With Nominatim it gives a starting point and list of location addresses for a search.

routes/geo.js calls it for /api/geo/me — how the map knows where to open before you type.

Overpass API

APIoverpass-api.de

Searching for places by tag, which a text search cannot do. Queries are capped, cached, and fall back to a mirror when busy.

routes/osm.js for business and services search; scripts/scoreZips.js for the heatmap sweep.

Nominatim

APInominatim.openstreetmap.org

Addresses, and turning a place name into coordinates. Rate limited and cached to respect its usage policy.

lib/nominatim.js holds the one-request-a-second queue every caller shares; routes/geo.js and routes/places.js call it.

Refuge Restrooms

APIrefugerestrooms.org

Community-logged gender-neutral and accessible restrooms, with filters for each.

routes/restrooms.js; scripts/scoreZips.js counts a documented restroom nearby as a safety signal.

US Census Bureau

Published filecensus.gov

The 2020 ZIP Code Tabulation Area boundaries the heatmap is drawn on — a published file rather than a live API.

scripts/seedZctas.js loads it into the zctas collection.

HRC Corporate Equality Index

By handhrc.org

Company workplace-policy scores. HRC publishes no API, so these are transcribed by hand and each entry links to its source.

data/cei.json holds them; routes/cei.js serves them.

Surgeon directory

Compiled by handr/TransSurgeriesWiki

817 entries from the r/TransSurgeriesWiki Reddit wiki, 747 from the phallo.net FTM surgeon directory and 32 from TransHealthCare. 262 addresses verified against the NPI Registry, and 723 entries checked by hand against each surgeon's own practice page.

data/surgeons.json holds the directory; routes/surgeons.js serves it.
